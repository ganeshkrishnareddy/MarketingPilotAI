# MarketingPilot AI

An automated, AI-powered digital marketing SaaS platform.

## Architecture

This project is organized as a monorepo containing:

- **frontend/**: Next.js (React), TypeScript, Tailwind CSS, Shadcn UI
- **backend/**: FastAPI (Python) for AI orchestration and core business logic
- **database/**: Supabase SQL schemas
- **docs/**: Architectural documentation and API references

## Features

- **Module 1**: Business Onboarding
- **Module 2**: AI Business Analysis
- **Module 3**: AI Content Studio
- **Module 4**: AI Image Studio
- **Module 5**: Content Calendar
- **Module 6**: Social Media Manager
- **Module 7**: Meta Ads AI
- **Module 8**: Email Marketing
- **Module 9**: SEO Assistant
- **Module 10**: Analytics Dashboard
- **Module 11**: AI Copilot
- **Module 12**: Automation (n8n)
- **Module 13**: Approvals & Workflows
- **Module 14**: Workspace & Teams
- **Module 15**: Billing & Subscriptions

## Prerequisites

- Node.js (v18+)
- Python (3.10+)
- Docker & Docker Compose
- Supabase CLI (optional, for local development)
